# Appointment Calendar Split Layout

The advanced appointment calendar keeps day, week, month, staff/status filters,
mechanic assignment, advanced statuses and drag-and-drop rescheduling.

The calendar UI was restored to a professional split layout:

- calendar on the left;
- selected-day appointment list on the right;
- clicking a date updates the right panel;
- appointment actions remain available in the right panel;
- responsive stacking on smaller screens;
- no database migration required.
